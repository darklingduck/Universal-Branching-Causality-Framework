# Open Questions

UBCF intentionally preserves unanswered questions rather than forcing conclusions beyond the framework's current support.

## Time
- Is time fundamental or emergent from causality?
- Can time exist without events?
- What would it mean to step outside time?
- Would leaving one temporal structure simply place an observer into another structure with different fundamental laws?
- Was there a meaningful state before the first change?

## Branches
- Can a branch truly terminate, or can it persist indefinitely in a static or near-static state?
- What is the exact physical threshold for two outcomes to be distinguishable enough to constitute separate branches?
- How should continuous physical outcome spaces be represented?

## Identity
- What is the fundamental nature of consciousness underlying an ICS?
- Under what conditions does the total set of continuations of an ICS end?
- Can an ICS persist indefinitely if a branch contains causal developments that indefinitely extend life or awareness?

## Physics
- Can fundamental laws differ between branches or nested universes?
- How should UBCF connect mathematically to quantum mechanics?
- Can UBCF yield testable predictions that distinguish it from other branching or causal models?

## Information
- Is information merely a description of Causal Lineage, or is it physically fundamental?
- Is information conserved across branching, and what would conservation mean when histories share a common past?

## Origins
- Is there a first branch or first Event Branch Node?
- What, if anything, preceded the earliest causal event?
- Why does reality preserve multiple causal continuations rather than only one?
