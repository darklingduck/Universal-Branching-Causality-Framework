# UBCF Project Goals

## Primary Goal
Preserve and develop the Universal Branching Causality Framework as a coherent, version-controlled archive.

## Current Priority
The current priority is archival completeness. Existing ideas, definitions, examples, uncertainties, and speculative extensions should be captured before major rewriting or publication work begins.

## Development Method
- The originator defines and decides the framework.
- Questions are used to expose assumptions, missing cases, and possible contradictions.
- Established concepts are separated from interpretations, hypotheses, and unanswered questions.
- Git history preserves how the framework changes over time.

## Long-Term Goals
- Produce an internally consistent specification.
- Develop mathematical descriptions where useful.
- Compare UBCF with relevant scientific and philosophical frameworks.
- Investigate whether the framework can produce testable consequences.
- Derive future papers and presentations from the canonical archive.
