# UBCF Core Axioms

## Axiom 1: Causal Ordering

Reality is organized through causality. Events occur in an ordered structure where previous conditions influence future states.

## Axiom 2: Branching Through Causal Divergence

When a causal event has multiple distinguishable outcomes, an Event Branch Node occurs and each distinguishable outcome continues as its own branch.

## Axiom 3: Branch Independence

Once branches diverge, each branch develops its own unique Causal Lineage. Identical recreation of a previous branch is impossible because the causal history has changed.

## Axiom 4: Identity Continuity

Immediately before divergence, an Identity Continuity Structure has one shared pre-branch state. At the Event Branch Node, each resulting branch inherits an equivalent copy of that state. After divergence, each ICS experiences only its own branch-local causal continuation; no pre-existing observer selects which branch to follow.

## Axiom 5: Local Branch Formation

A branch does not duplicate all prior history. All events before an Event Branch Node are shared. Divergence begins at the causal event creating the branch.

## Axiom 6: Universal Applicability

Branching is not limited to conscious choices. Any causal event with distinguishable outcomes may create branches.

## Axiom 7: Knowledge Limitation

Observers exist within the causal structure they experience and cannot directly determine conditions outside their accessible causal lineage.

## Axiom 8: Temporal Linearity

Within a branch, causal time remains forward-ordered. Time itself does not loop backward. A traveler may move to an earlier temporal position, but that displacement creates new causal continuations rather than reversing the branch's own time order.

## Axiom 9: Causal Alteration Preservation

An intervention cannot overwrite an established causal continuation. The unaltered continuation remains, while the intervention creates an altered branch. Artificial modification therefore adds causal divergence rather than erasing the prior continuation.
