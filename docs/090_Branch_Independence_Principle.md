# Branch Independence Principle (BIP)

## Definition

Once an Event Branch Node occurs, each resulting branch develops an independent Causal Lineage.

Because the causal history after divergence is different, branches cannot become identical and merge.

## Shared History

Branches share all events before the Event Branch Node.

After divergence:

- Information develops differently.
- Events occur differently.
- The Causal Lineage becomes unique.

## Implication

A branch cannot return to being the original branch. Even if a future state appears identical, the path taken to reach that state is different.
