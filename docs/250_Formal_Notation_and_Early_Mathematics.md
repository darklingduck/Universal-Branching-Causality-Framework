# Formal Notation and Early Mathematics

## Purpose

Preserve the mathematical notation introduced during early attempts to formalize UBCF. These expressions are archival and provisional; they are not yet a complete mathematical theory.

## Event and Causal Graph

Reality was represented as a graph:

`G = (E, C)`

where:

- `E` is the set of events.
- `C` is the set of causal relationships between events.

## Temporal Ordering

A basic temporal relation was proposed:

If `E1 -> E2`, then `T(E1) < T(E2)`.

This expresses the idea that if one event causally precedes another, its temporal ordering is earlier within that causal lineage.

## Branching Event

A branching event may be represented as:

`E_n -> {E_n1, E_n2, E_n3, ...}`

The number of resulting continuations is not assumed to be binary. It depends on the number of distinguishable outcomes of that event.

## Identity Continuity

An early identity expression was:

`I_total = {I_b1, I_b2, ..., I_bn}`

This represented all branch-specific instances that share a common identity history prior to divergence.

Later terminology replaced this informal identity notation with the Identity Continuity Structure (ICS).

## Branch Distinction

Two branches can approach similar physical states without becoming the same branch:

`Branch_A != Branch_B`

Even where:

`State_A ~= State_B`

The difference is preserved by their distinct Causal Lineages.

## Branching Factor

A possible future formal quantity was discussed:

`B(E) = number of distinguishable continuations of event E`

This remains exploratory because defining and quantifying all distinguishable outcomes may itself alter the observational description of the system.

## Status

These expressions are preserved as the earliest formal vocabulary of UBCF. They require later consistency, mathematical rigor, and comparison with established causal graph and quantum formalisms before being treated as canonical mathematics.
