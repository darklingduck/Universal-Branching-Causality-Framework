# Branch Selection Mechanism

## Normal Branching

In UBCF, normal causality does not require probability to select a branch.

A causal event creates distinguishable outcomes, and each outcome develops as its own branch.

## Probability

Probability becomes relevant when causal history is skipped or bypassed.

The primary example is time travel. A traveler entering a different point in time has bypassed the choices and events that would normally create that future path.

## Time Travel Selection

The knowledge of the traveler does not determine the destination branch unless a method exists to map causality.

Even with such a map, returning to the original branch is impossible because leaving already created a new causal history.
