# UBCF Glossary

## Universal Branching Causality Framework (UBCF)

A framework describing reality as an evolving structure of causal histories where distinguishable causal outcomes create independent branches.

## Event Branch Node (EBN)

A causal event where multiple distinguishable future outcomes exist and each distinguishable outcome continues as its own branch.

An internal thought or consideration alone does not create an EBN unless it produces a physical causal change.

## Identity Continuity Structure (ICS)

The continuity of an observer's awareness through a branch. Immediately before an Event Branch Node, there is one shared ICS state. At divergence, each resulting branch inherits an exact copy of that state, after which each ICS continues only within its own branch-local causal history.

## Causal Lineage

The accumulated sequence of causal events leading to a branch's current state. Branches share the same lineage before divergence and develop unique lineage after an Event Branch Node.

## Branch Independence Principle

Branches cannot become identical or merge because each branch contains a unique causal lineage after divergence.

## Observer Continuity Problem

The question of how awareness experiences branching. Each post-divergence ICS experiences only its own branch-local continuation.

## Skipped-Causality Branch Resolution (SCBR)

The mechanism used when an entity ceases causal participation across an interval and later re-enters the causal structure without a continuous Causal Lineage through the intervening Event Branch Nodes. SCBR governs how the destination continuation is resolved; it does not imply deliberate branch selection or navigation.

## Causal Alteration Preservation

An intervention cannot overwrite an already-established causal continuation. The unaltered continuation remains, while the intervention produces an altered branch.
