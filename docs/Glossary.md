# UBCF Glossary

## Universal Branching Causality Framework (UBCF)

A framework describing reality as an evolving structure of causal histories where distinguishable causal outcomes create independent branches.

## Event Branch Node (EBN)

A causal event where multiple distinguishable future outcomes exist and the realization of one outcome creates a new branch.

An internal thought or consideration alone does not create an EBN unless it produces a physical causal change.

## Identity Continuity Structure (ICS)

The continuity of an observer's awareness through a branch. At the moment before a branch event, resulting ICS instances are exact copies. Divergence occurs when the causal event is realized.

## Causal Lineage

The complete sequence of causal events and choices that produces a specific branch.

## Branch Independence Principle

Branches cannot become identical or merge because each branch contains a unique causal lineage after divergence.

## Observer Continuity Problem

The question of how awareness experiences branching. An ICS experiences only the branch created by its causal continuation after an Event Branch Node.
