# UBCF Repository Roadmap

## Primary Goal
Maintain this repository as the canonical living archive of the Universal Branching Causality Framework.

## Phase 1 — Preserve the Base Archive
**Status: In progress**

- Establish files for all major concepts.
- Preserve existing core documents without premature rewriting.
- Capture missing historical, speculative, example, and open-question material.

## Phase 2 — Populate and Expand
**Status: Pending**

- Move all recoverable framework information into the appropriate archive files.
- Expand examples and explanations.
- Add relationship maps and navigation.

## Phase 3 — Consistency Review
**Status: Pending**

- Check every definition against the rest of the framework.
- Resolve contradictions.
- Standardize terminology.
- Record changes rather than erasing development history.

## Phase 4 — Formalization
**Status: Pending**

- Mathematical model.
- Diagrams.
- Comparison with existing scientific and philosophical frameworks.
- Testability analysis.

## Phase 5 — Publication
**Status: Pending**

- Produce a formal paper from the canonical archive.
- Prepare references and figures.
- Seek external review.

## Archive Rule
The paper is an output of the repository. The repository is not merely supporting material for the paper.
