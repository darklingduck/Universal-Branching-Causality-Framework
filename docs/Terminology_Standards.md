# Terminology Standards

This file records preferred UBCF terminology so later revisions can remain consistent.

## Universal Branching Causality Framework (UBCF)
The name of the overall framework.

## Event Branch Node (EBN)
The point at which a causal event has multiple distinguishable outcomes that produce divergent causal continuations. Each distinguishable outcome continues as its own branch.

## Causal Lineage
The accumulated sequence of causal events leading to a branch's current state. Lineage may be shared before divergence and becomes unique after an Event Branch Node.

Preferred spelling is **causal**, not **casual**.

## Identity Continuity Structure (ICS)
The structure used to describe continuity of an observer or identity through causal branching. Immediately before an EBN there is one shared ICS state; resulting branches inherit equivalent copies at divergence.

## Branch Independence Principle (BIP)
The principle that divergent branches remain causally distinct and do not merge into an identical lineage.

## Observer Continuity Problem
The problem of describing why a branch-local observer experiences only its own post-divergence causal continuation despite exact continuity immediately before an EBN.

## Skipped-Causality Branch Resolution (SCBR)
The mechanism used when an entity ceases causal participation across an interval and later re-enters without a continuous Causal Lineage through the intervening Event Branch Nodes.

SCBR replaces the earlier working term **Branch Selection Mechanism**. The word **resolution** is preferred because SCBR does not imply that a traveler deliberately selects or navigates to a branch.

### Primary Application: Forward Time Travel Branch Resolution
A true forward temporal displacement that skips causal participation invokes SCBR.

### Relativistic Travel
Relativistic time dilation does not invoke SCBR because causal participation remains continuous even when observers experience different amounts of proper time.

## Causal Alteration Preservation
The principle that an artificial intervention cannot overwrite an established causal continuation. The unaltered continuation remains, while the intervention creates an altered branch.

## Choice
In informal discussion, 'choice' may refer either to a conscious decision or to a non-conscious causal divergence. Formal writing should prefer **causal event**, **causal outcome**, or **causal continuation** when consciousness is not required.

## Branch
A causally distinct continuation following an EBN. Branches share their pre-divergence Causal Lineage.

## Canon / Working Hypothesis / Open Question / Historical Material
Archive material should be identified by status where ambiguity could otherwise make a speculative extension appear to be a core UBCF rule.
