# Revision Principles

## Preserve Before Refining
Material should first be captured accurately. Refinement comes after archival completeness.

## Do Not Erase Development History
When a definition changes substantially, preserve the earlier reasoning through Git history and, when useful, historical archive notes.

## Distinguish Source and Interpretation
A proposed clarification should not silently become a UBCF rule. The originator's accepted definition, explanatory interpretation, speculative extension, and open question should remain distinguishable.

## Propagate Changes
When a core concept changes, review every dependent document for contradictions.

## Prefer Internal Consistency
New terminology or mechanisms should use existing UBCF rules where possible rather than introducing unnecessary exceptions.

## Preserve Epistemic Boundaries
A question does not require an invented answer. Unknown or currently unobservable matters should remain identified as open when the framework cannot justify a conclusion.
