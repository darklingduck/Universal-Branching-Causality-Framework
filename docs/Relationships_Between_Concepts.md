# Relationships Between Concepts

This is an initial dependency map for the archive. It will be refined after all concept documents are populated.

## Core Flow
Time / causal ordering
→ causal events
→ Event Branch Nodes
→ branches
→ unique Causal Lineages
→ branch-local Identity Continuity Structures

## Event Branch Node
Depends on:
- causality;
- distinguishable outcomes.

Used by:
- branch formation;
- Causal Lineage divergence;
- ICS divergence;
- time-travel departure and arrival.

## Causal Lineage
Depends on:
- ordered causal events;
- branch history.

Supports:
- Branch Independence Principle;
- branch information history;
- identity development;
- attempted causal mapping in time-travel scenarios.

## Identity Continuity Structure
Depends on:
- Causal Lineage;
- Event Branch Nodes;
- branch-local experience.

Supports:
- Observer Continuity Problem;
- duplicate/older-younger traveler scenarios;
- branch-local life and termination.

## Branch Independence Principle
Depends on:
- unique post-divergence Causal Lineage.

Supports:
- non-merging branches;
- impossibility of truly returning to an originating branch;
- paradox avoidance in time travel.

## Time Travel
Uses:
- Event Branch Nodes;
- Causal Lineage;
- Branch Independence Principle;
- ICS;
- special probability considerations when intermediate causality is skipped.

## Cosmological and Quantum Applications
These extend the core concepts but are not currently required to define the core framework.
