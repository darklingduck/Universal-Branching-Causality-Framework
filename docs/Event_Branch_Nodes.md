# Event Branch Nodes (EBN)

## Definition

An Event Branch Node is a causal event where multiple distinguishable future causal states exist. The realization of one state creates a new branch.

## Conscious and Non-Conscious Events

An EBN does not require a conscious entity.

Examples:

- A person making a physical decision.
- A meteor collision changing an impact path.
- A biological mutation affecting development.
- A stellar event altering future conditions.

## Internal Thoughts

A thought or internal consideration does not create an EBN by itself. A branch occurs only when the possibility becomes a physical causal change.

## Branching Factor

An EBN does not have to produce only two outcomes. A single event may create any number of distinguishable outcomes.

Example:

A selection among one million possible outcomes creates one million possible branch continuations.

## Hierarchical Events

Multiple stages of decision-making represent multiple Event Branch Nodes rather than one large branch.

A process of elimination followed by selection consists of a sequence of causal branching events.
