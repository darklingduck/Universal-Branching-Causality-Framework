# Universal Branching Causality Framework (UBCF)

## Overview

The Universal Branching Causality Framework (UBCF) is a conceptual framework describing reality as an evolving structure of causal histories. Reality is represented as a branching structure where distinguishable causal outcomes produce independent branches.

This repository serves as the working specification and historical record of UBCF. The goal is to preserve definitions, refinements, questions, and future formal development.

## Core Concepts

- Event Branch Node (EBN)
- Causal Lineage
- Branch Independence Principle
- Identity Continuity Structure (ICS)
- Observer Continuity Problem
- Branch Selection Mechanism
- Time and Causality
- Time Travel Applications

## Development Philosophy

UBCF is developed through defining concepts, testing internal consistency, identifying unresolved questions, and refining terminology.
